# Project conventions

- Write all project reports, documentation, and code comments in English. Conversation with the user may remain in Turkish.
- Preserve existing analysis content, calculations, filters, and rounding unless the user authorizes a change.
- Ask before correcting a SQL query unless the user has already approved that specific correction. Keep unresolved drafts intact until their scope is agreed.
- Preserve the original snapshots under `.local/backups/`; do not translate or overwrite their historical contents.
- Record actual query exports in `outputs/`. Do not present reconstructed conversation values as fresh database results.
